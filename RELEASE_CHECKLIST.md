# Release Checklist

- [ ] Public types, README, MIGRATING, and CHANGELOG agree.
- [ ] Quality, full audit, production audit, and package dry-run pass.
- [ ] Cookie, CSRF, CORS, origin, callback, refresh, and logout tests pass.
- [ ] Consumers pass against the release candidate.
- [ ] The npm trusted publisher is configured and provenance is present.
- [ ] The tag and package version match and have not been reused.
